# ISPI Cakes and Pastries

A modern, responsive website for **ISPI Cakes and Pastries**, a Lagos-based cake and pastry business offering custom cakes, pastries, event catering, and related services.

The website is designed to showcase the brand's products and services while making it easy for customers to explore the menu, view previous work, learn about the business, and place enquiries through WhatsApp.

## Live Website

[ISPI Cakes and Pastries](https://ispicakesandpastries.netlify.app/)

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern bakery and pastry-focused UI
- Hero section with prominent calls to action
- About section introducing the business
- Cake and pastry gallery
- Pricing / menu section
- Services section
- Customer testimonials
- FAQ section
- Blog section
- Contact and enquiry section
- WhatsApp ordering integration
- Responsive navigation
- Smooth scrolling between sections
- Scroll-to-top functionality
- Custom 404 / Not Found experience for invalid URLs
- SEO-focused local business content
- Google Analytics integration
- Structured data for search engines
- Responsive layouts for large desktop screens

## Sections

The website includes:

- **Home** — Introduction and primary calls to action
- **About** — Information about ISPI Cakes and Pastries
- **Gallery** — Showcase of cakes, pastries, and previous work
- **Pricelist** — Products and pricing information
- **Services** — Catering and other available services
- **Testimonials** — Customer feedback
- **Blog** — Articles and updates
- **FAQ** — Frequently asked questions
- **Contact** — Customer enquiry and ordering form

## Local Development

Because this is a static HTML project, no framework or build process is required.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate into the project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Open the project

You can open `index.html` directly in your browser, or use a local development server such as VS Code Live Server.

## WhatsApp Enquiries

The website includes WhatsApp integration to make it easy for customers to contact ISPI Cakes and Pastries about orders and enquiries.

The enquiry flow can include customer information, order details, quantities, pricing, and other relevant delivery information.

## Responsive Design

The website is designed to work across different screen sizes, including:

- Mobile devices
- Tablets
- Laptops
- Desktop displays
- Large desktop screens

Additional responsive breakpoints are used to maintain spacing, typography, layouts, and visual balance on larger displays.
